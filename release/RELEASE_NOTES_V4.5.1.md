## V4.5.1 更新内容

- Smart ROI 缓存最终掩码与数据拓扑；删点、撤销、滤波、残差显示、重绘和切页不再重复建图或抓面。
- 连续曲面生长升级为 Fast Accept、Fast Reject 与灰区精细拟合的粗到细流程，平滑面基准提升约 8.7 至 9.8 倍。
- XY、XZ、YZ 三个视图均可选择真实 XYZ 种子，可区分 XY 投影重叠的多层表面。
- 支持在 XY、XZ、YZ 预先框定候选范围，多个范围取交集；残差视图仅用于选点，抓面始终使用真实变换后 Z。
- 首次抓面统一在后台运行，提供阶段进度、取消和拓扑/Grow/Fast/Slow/分析/绘图耗时统计。
- Recipe 升级为 schema 6，新建 Smart ROI 使用 V3 算法；V4.5.0 V2 与更早 legacy ROI 继续按原算法重放。
- 安装包内新增重叠双层、Bow、孔洞与台阶组合 Demo，便于验证多视图选层和连续曲面边界。

## 准确性与性能验证

- V4.0.3 长期使用 Demo 作为 Golden Sample；关闭滤波、MAD、局部中位数和 3-Sigma 四种模式下，点掩码、平面系数、Rx/Ry、TTV、PV、RMS 与 V4.0.3 完全一致。
- 10,062 / 50,180 / 120,000 点平滑面基准分别提升 9.84 / 8.75 / 8.73 倍，输出掩码 IoU 均为 1.0。
- 自动化测试 44 项全部通过。
- 打包程序启动自检、Windows Setup 静默安装、自检和卸载闭环通过。

## 安装提示

适用于 64 位 Windows。下载 `SurfaceRxyZxyAnalyzer_Setup_V4.5.1.exe` 安装，可直接覆盖旧版。用户 Recipe 和设置保存在安装目录之外，升级不会清除。当前安装包未进行商业代码签名，Windows SmartScreen 可能显示未知发布者提示。
