# V5.0.3 — 深色模式

- 新增深色模式：左侧模块栏最底部新增主题按钮（浅色显示太阳，深色显示月亮），可选「浅色 / 深色 / 跟随系统」，选择自动记忆并在下次启动时恢复。
- 深色配色为中性近黑底、细边框、低饱和：主按钮为白底黑字，导航与次级按钮仅用灰阶，绿 / 红只用于合格 / 不合格。
- 四视图、膜厚配准图、平行度 3D 图和调整面板的背景、坐标轴、刻度、网格、图例随主题切换；测量色标（colormap）与数据颜色不变。
- 导出的单层、膜厚、平行度报告始终保持白底，便于打印和归档。
- 测量、滤波、配准、判定和导入的计算定义不变。

## 验证

- 新增主题测试 5 项通过（按钮位置与菜单、偏好记忆与启动恢复、样式往返、跟随系统、图表外框随主题且色标与报告不变）；界面、判定、膜厚配准、色标和报告相关测试通过。
- 已知旧矩阵 Pitch 测试问题不属于本次修改。

## 安装与校验

Release 附件包含完整 Windows 安装程序、对应 `.sha256` 和 `update_manifest.json`。安装前核对 SHA-256。沿用原 AppId 以支持覆盖升级；可选格式扩展不包含在主安装包中。安装包仍未进行代码签名。
