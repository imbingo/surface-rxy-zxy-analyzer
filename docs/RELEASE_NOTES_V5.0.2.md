# V5.0.2 — 胶厚配准误差均值与结果判定

- 膜厚结果条新增「配准误差均值 (µm)」：容差内匹配点到堆叠总成的 XY 最近邻距离均值；两片单片时显示「单片1 / 单片2」，悬停显示每层均值、RMS、Max。
- 匹配质量报告、自动精对齐提示和膜厚报告同时给出配准误差均值与 RMS；与平面残差 RMS 相互独立。
- 新增结果判定：单层、膜厚、平行度三个模块的指标条末尾各增加一张「结果判定」卡片，显示合格 / 不合格 / 未设规格。
- 在「Recipe ▸ 判定规格…」或点击判定卡片设置上限：|Rx|、|Ry|（µrad，按绝对值）、平面残差 PV、TTV（µm）、平行度合成夹角（µrad）。任意一项超出即判定不合格，超差指标数值标红；未算出的指标显示「--」，不会判为合格。
- 判定规格自动记忆并随 Recipe 保存；旧 Recipe 不含该项时保留当前规格。判定结论写入单层报告、膜厚报告和平行度结果。
- 测量、滤波、配准和导入的计算定义不变。

## 验证

- 新增判定与配准均值测试 9 项通过；膜厚配准、界面、报告布局、模块导航和色标相关测试通过。
- 已知旧矩阵 Pitch 测试问题不属于本次修改。

## 安装与校验

Release 附件包含完整 Windows 安装程序、对应 `.sha256` 和 `update_manifest.json`。安装前核对 SHA-256。沿用原 AppId 以支持覆盖升级；可选格式扩展不包含在主安装包中。安装包仍未进行代码签名。
