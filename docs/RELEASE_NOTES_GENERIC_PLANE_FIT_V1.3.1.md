# 通用三维拟合 1.3.1

适用于面型与 Rxy 分析 V5.0.9 及以上版本。退出主程序后运行独立扩展安装包，然后重新打开主程序。

- **坐标系与基准增强**：两面定基准新增「反转 A 法向 (X′)」「反转 B 法向 (Y′)」开关，并在 3D 视图绘制构建出的 `(X′, Y′, Z′)` 基准三轴（基准面 A 坐标系同步绘制）；两参考面偏离直角超过 5° 时自动告警。
- **状态隔离与防呆**：2 槽模式下彻底隔离隐藏槽位 C（检查列表、计算、状态栏与 JSON 导出均不再串入）；两面定基准导出 JSON 的 `common_frame` 同步校验 C 槽；三点建基准下 B 槽未拟合时禁用导出；修正「偏离直角」在非两面模式误显示的问题。
- **告警与错误直出**：槽位拟合失败（如共线点集）与几何质量警告（如多面散布）直接在主界面、侧栏与质量卡片醒目提示；在非原坐标系模式下过滤垂直参考面的源坐标投影角干扰告警。
- **交互与视觉打磨**：统一 3D 默认及复位视角至 V5.0.9 `(45°, -135°)`；所有下拉框改用防滚轮误触控件；修复 Step 2 坐标系定义卡片下拉框截断；适配深色模式 3D 箭头描边并支持主题切换实时同步；新增单槽「清空」、槽位「交换 A / B」、顶部指标复制与「复制摘要」；保留 XZ／YZ 选点视图与投影缩放状态，并改用均匀抽样显示残差异常点。
