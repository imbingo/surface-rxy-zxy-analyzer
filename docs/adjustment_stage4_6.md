# 装调功能：阶段 4–6

## 入口与操作

在“平行度分析”设置基准面、测量面并计算平行度，然后打开左侧
“4 装调计算”，或右侧同名子页。主控原有量测定义保持不变。

装调页支持基准面目标、自定义 Rx/Ry/Z0 目标；三种参考原点；三点/四角模板；
任意数量支撑点的添加、复制、重命名、坐标与垫片编辑、删除和清空。
模板是示例坐标，必须改为实际接触点，且与两面坐标系一致。
复制点后先改坐标，重复坐标不能计算。每点步进留空时采用全局步进。
基础厚度超限警告；理论/推荐厚度超限标红并保留原始计算值，不静默截断。

结果显示当前/目标 Z、E、理论 H、基础厚度、理论厚度、推荐厚度、实际调整量、
量化误差、状态；同时显示调整前/预计残余 Rx、Ry、ΔZ0、最大实际调整幅度。
预览为理论补偿平面、支撑点、Z 向箭头及各点带符号调整量。
窄窗口参数表单自动切为单列，宽结果表独立横向滚动，页面纵向滚动。

## 共面性

对实际调整高度 H_actual 拟合最佳平面。残差 r=H_actual-H_fit，
单位 µm。PV=max(r)-min(r)，RMS=sqrt(mean(r²))，最大偏离=max(abs(r))，
最差点取绝对残差最大的点（相同值取首次出现者）。采用中心化归一化矩阵
直接计算残差，避免还原全局截距后的消减误差。

N>=4 时显示静力学过约束提醒；PV 严格大于用户阈值时显示橙色不共面警告。
阈值默认 5 µm，可保存到 Recipe。预测不包含刚度、预紧力和真实接触力学。
不会为消除报警而自动修改推荐垫片。

## 状态联动

修改任一装调输入立即清空结果、卡片和预览，禁用导出与复制。
设置/交换/清空两面、重新计算平行度、主控处理/ROI 更新也使装调结果失效。
主控更新同时清空平行度结果，但两面槽仍遵守原有“设置时快照”语义；
提示用户重新设置对应面并计算。后台平行度计算用面对象与修订号验证，
已被换面或输入变更作废的晚到结果不会恢复旧装调可计算状态。
后台任务运行期间装调面板禁用。未启用或缺少有效平行度/两面时不能计算。

## Recipe 与导出

Recipe schema 从 7 升至 8，新增 adjustment_config，保存启用、目标模式、
自定义目标姿态、原点模式/坐标、所有支点/基础/min/max/步进、量化与共面阈值。
不保存当前 DUT、装调结果或预计残差。旧 schema 缺少装调配置时使用默认三点配置；
未知未来 schema 拒绝加载。装调配置先验证，再更改 UI。加载 Recipe 清空两面槽和
全部平行度/装调结果，必须重新设置两面并计算。旧版本应用不支持 schema 8。

装调 CSV 包含项目/Recipe、时间、来源、估计状态、配置快照、原点、两面系数及
姿态、当前误差、逐点结果、预计残差、共面统计、可执行状态与警告。
使用 UTF-8 BOM 和标准 CSV 引号；通过同目录临时文件原子替换目标文件。
复制结果包含目标、原点、调整前后、逐点理论/实际调整、厚度和警告。
