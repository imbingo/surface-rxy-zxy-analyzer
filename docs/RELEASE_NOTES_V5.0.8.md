# V5.0.8

## 使用与升级

- 主程序：`SurfaceRxyZxyAnalyzer_Setup_V5.0.8.exe`。
- 可选 VIG 像面扩展：`SurfaceAnalyzer_VigImageExtension_Setup_V1.2.0.exe`，最低主程序版本 V5.0.8。使用 VIG 时请同时升级；不使用 VIG 时无需安装扩展。
- 主程序与扩展保持原 AppId，支持覆盖升级。扩展格式包仍为独立可选组件。

## 主要改进

- 膜厚、平行度、VIG 增加以当前分析示例为基础的批量入口，复用原有分组确认、逐组处理和组合 Recipe；各角色保留独立处理参数。
- 膜厚计算后自动切换至单层主控，载入独立编辑副本，沿用主控四视图、二次分析及报告导出。
- VIG 增加输入有效性检查、匹配／有效／成功点数及失败位置追溯，便于定位部分 slit 未参与结果的原因。
- 修正主控显示面型和色标控件布局；改进指标卡换行、数值字号、窄窗口与高 DPI 布局。
- 调整主控、平行度、VIG 报告的三维图位置、大小及留白；修复平行度预览图文重叠和主控缩放恢复后的多余滚动。
- 主控顶部 3σ 启动默认隐藏，可在“判定规格”中勾选；主动加载 Recipe 时恢复配方保存的显示选择。
- 改善 Recipe 搜索框输入、提示和选中文字的浅色／深色对比度。
- 包含 V5.0.7 的 PLUX 拖拽／最近文件、VIG 四视图、组合 Recipe、主控二次分析及可选扩展打包修复。

## 验证及边界

发布流程要求 Windows 定向回归、源码 GUI 与真实计算子进程、打包 EXE 的有／无扩展验收、主程序隔离安装及覆盖升级、扩展安装及升级全部通过，才允许发布。附件 `validation-summary.json` 记录构建提交及安装包 SHA-256；验证资料包包含日志、报告和截图。

未运行已知可能卡住的完整测试套件。旧 VIG 黄金数值用例在 Linux 下存在略超容差的既有差异，本版未修改公式或放宽断言；详见修改说明。双 slit 验证使用合成数据，尚未取得用户真实文件，不能声称已确定其文件的唯一根因。
