# V4.7.8 — 大矩阵单遍导入、像素尺寸溯源与手动列映射

## 大矩阵 CSV 导入

- 将矩阵正文完整性校验、有效点统计和抽样合并到同一次数值扫描，抽样完成后不再从头解析矩阵。
- 普通数值行使用严格完整字段校验及 NumPy 数值转换；引号、空字段、No Data 等继续使用兼容解析流程。
- 保留完整扫描与取消能力。仍需读取文件正文，不能将抽样误认为只读入少量字节。
- 按矩阵格点总数自适应调整行列倍率，使用可嵌套采样格点；不再取满点数上限就停止扫描。稀疏矩阵、超宽矩阵后部也会纳入抽样覆盖。
- 空间网格采用有界流式网格合并，保留每格代表点与 Z 最小/最大值，避免按有效点逐条重复解析。
- Excel 倍率采样同样按矩阵尺寸约束分析点数上限。Excel 本身仍先读取工作表。

## 实际 X/Y 像素尺寸

- 左侧“列映射与单位”区域、导入状态与报告明确显示实际使用的原始 X/Y 像素间距（µm/像素）及来源。
- 默认值为 X=47.242、Y=47.242 µm/像素；实际导入按用户设置或文件中可靠的 XY 校准 / Pitch 元数据执行。
- 倍率采样额外显示最终倍率 N 和采样点间距 N×原始像素间距；空间网格采样显示“抽样点间距不固定”。
- 只有尺寸或 Z 单位元数据时，不再将 XY 默认间距标为可靠文件校准。只有一个轴的 Pitch 元数据时，分别标明两轴来源。
- XYZ 物理点表直接按各轴单位换算，不套用矩阵像素间距。

## 无法确定 XYZ 列时

- 文件已解析但无法确定 XYZ 语义时，保留原始列名与已读数据，提示用户在“列映射与单位”中选择三个不同的数据列及各轴单位后应用。
- 无表头且恰好三列也需要用户确认，不再仅凭列数假定 XYZ 顺序。
- 列下拉菜单提供前五行值的提示，帮助辨认原始列。
- 修复正常后台导入遇到待映射状态时错误回滚成上一次数据的问题；待映射是正常步骤，不显示为导入失败。
- 待映射时清除旧分析结果与图形，防止把旧图误认为新文件结果。确认映射后重新计算。
- 支持 mm、µm、nm；明确指定的手动列号、单位和 Recipe 继续按原配置应用。

## 验证

新增单遍解析计数、稀疏和超宽矩阵覆盖、流式网格极值、严格字段校验、关闭抽样全量导入、像素间距显示、报告和后台待映射流程回归测试。

`benchmarks/benchmark_matrix_import.py` 可生成约 600MB、3999 行的模拟 CSV，对比 V4.7.7 与当前版本的纯导入耗时。它不包含后续拟合和绘图，也不代表特定仪器文件的实际耗时。

本机使用 Python 3.12.10、同一生成方式的 3999×10000 纯数值 CSV（599,850,000 字节），依次测量得到：

| 版本 | 纯导入耗时 | 正文数值扫描 | 有效点 / 分析点 |
| --- | ---: | ---: | ---: |
| V4.7.7 | 217.274 秒 | 2 次 | 39,990,000 / 100,000 |
| V4.7.8 | 21.305 秒 | 1 次 | 39,990,000 / 100,000 |

两次使用相同设置（N 起始值 10、上限 100,000、X/Y=47.242µm/像素），最终 N=20，最后采样位置为 0 基第 3980 行、第 9980 列。上述为模拟文件测试，真实仪器 CSV 仍需使用用户原文件复核。
