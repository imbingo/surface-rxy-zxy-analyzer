# V4.7.5 发布说明

V4.7.5 让通用导入策略以用户选择为准，修正 3D 默认观察方向，并为三个投影视图增加源点坐标悬停。

## 主要变化

- XYZ 点表、Pixel XY 与 Z Matrix 不再因抽样推断为另一种通用布局而被预检阻断。
- 八列及更多列的 XYZ 点表可以进入用户选择的 XYZ 解析与列映射流程。
- 明确的 Zygo 与 Precitec 厂商头继续使用受保护的专用解析流程。
- 3D 默认和双击复位视角改为 +X 向右后方、+Y 向左后方、+Z 向上的对称 45°视角。
- XY、XZ、YZ 投影视图按住 Ctrl 后支持悬停显示真实源点的 X、Y 和当前显示 Z；滤波或去趋势后同时显示原始 Z，普通鼠标移动不执行查询。
- 3D 场景保留边界留白，同时将绘图轴扩展到完整卡片并恢复大图比例，避免边角裁切且不缩小物料。

本版本不改变 Rx、Ry、PV、TTV、RMS、Mean Z、Smart ROI 或滤波算法的数学定义。
