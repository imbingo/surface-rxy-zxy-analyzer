## 验证范围

构建门禁包含九个测试文件，92 个定向测试，用例与进程均设超时。覆盖原有模块功能、配方与子进程、PLUX、规格／主题兼容，以及本版的示例参数冻结、膜厚手动／批量自动主控副本、工具栏字体和双 slit 逐阶段追溯。未运行已知存在既有失败／卡住风险的完整套件。

本地额外运行了数据规模统计测试（8 通过），VIG 引擎除既有黄金用例外的 10 个用例通过。正常输入的新旧引擎 image、焦距、主平面位置、残差和最终指标逐项完全一致，见 [基线比较记录](v508-screenshots/engine-baseline.json)。

**独立披露的既有失败：**`test_golden_image_and_plane_outputs_match_original_tool` 在本 Linux/SciPy 环境有约 1.129e-7 µm 偏差，超过原 1e-7 µm 容差。V5.0.7 基线同样复现；未修改光线公式、未降低原断言，也未将此用例计入上述全部通过的定向测试。Windows 门禁没有运行这一独立黄金用例。

## 验收边界

实际渲染主控、膜厚主控报告、平行度报告、VIG 四图及部分区域诊断，并使用真实组合计算子进程。仓库截图为 Linux Qt 源码实渲染；Windows EXE 的独立验收证据位于安装包附件 `validation/`。

双 slit 验证使用合成数据。仍未取得用户实际文件，因此不能声称已经定位其具体 slit 消失的唯一原因。诊断会明确未匹配、无效间距或光线失败发生的位置，便于用实际文件确认。

真实鼠标窗口管理器操作、用户设备高 DPI 和设备特有测量文件仍需人工复核。未合并 main、未创建 tag、未发布 GitHub Release。用户原有未跟踪的 `docs/user-guide-v5/` 保持不变。
