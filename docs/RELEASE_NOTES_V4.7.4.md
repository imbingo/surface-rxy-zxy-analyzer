# V4.7.4 发布说明

V4.7.4 修复宽 Physical XYZ 点表的格式预检误判，并优化主控 3D 面型图的默认显示尺寸和观察方向。

## 宽 XYZ 点表导入

此前预检主要检查前三列是否符合 XYZ，并在列数较多、列宽稳定且数值比例较高时倾向判断为 Z Matrix。因此，X/Y/Z 不在前三列，或前面包含序号、时间、质量、温度和设备字段的宽点表可能被错误拒绝。

现在预检会从完整表头中定位真实 X/Y/Z 列，并验证这些列的有效数值比例。支持 `X (mm)`、`Y Coordinate`、`Height (um)`、`X坐标`、`Y坐标`、`高度`等常见写法，也支持设备元数据位于真实表头之前以及以 `#` 开头的注释表头。

完全没有表头且所有列均为数值的宽文件在结构上可能同时符合点表和窄矩阵特征，此类文件仍建议明确选择导入策略并手动确认 XYZ 列映射。

## 3D 视图

主控 3D 场景放大，减少 Matplotlib 3D 坐标轴在卡片内部留下的空白，使有效绘图区更接近 X-Z 和 Y-Z 投影区。Z 轴标签间距同步调整，避免常见窗口宽度下文字被截断。

首次导入及双击复位采用水平 −45°、俯视 30°的工程观察方向，可同时观察 X/Y 方向和 Z 高度变化。用户手动旋转后仍保留当前视角。

## 兼容性

本版不改变 Rx、Ry、PV、TTV、RMS、Mean Z 的数学定义，也不改变空间高斯、MAD、局部中位数、迭代 σ 裁剪、ROI 和 Recipe schema 9 的行为。
