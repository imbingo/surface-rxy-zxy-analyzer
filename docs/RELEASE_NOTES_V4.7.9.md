# V4.7.9 — 更大的 3D 默认视图

- 修复 3D 自动缩放使用绘制前矩形坐标、实际绘制再变成正方形坐标，导致立体框重复缩小的问题。
- 按实际画布和当前相机投影计算最大安全倍率，检查真实坐标标签，避免框和标签被裁切。
- 3D 曲面允许使用完整画布的绘图区，不再被内部正方形裁剪边界截掉两侧。

- 移除“列映射与单位”下面重复的导入说明。底部导入状态、导入策略和报告保留实际像素间距及来源，不新增详情入口。
