# V4.6.6

- 四视图新增独立聚焦/还原按钮，聚焦占满右侧区域；Esc 还原，双击仍复位坐标。
- XY 分辨率自动适配画布，放大自动显示带高度颜色的原始散点，缺测区保持透明。
- 智能抓面增加邻接构建阶段、处理数量及用时反馈，并支持批次间取消。
- 二维图右键新增清空全部 ROI，以及未框选点时撤销最近一次删点。
- 提供四束区孔阵列 Demo 生成脚本。

Recipe schema 保持 8；旧分辨率设置兼容读取，统一使用自动上限 1200。量测计算口径与邻接判定保持不变。完整回归 184 项通过。

适用 Windows 10/11 x64。Setup 内含 Python 和依赖，默认安装到 Program Files，支持已有版本覆盖升级。用户设置保留在安装目录之外；升级前请保存当前未导出的工作。安装包未签名，Windows SmartScreen 可能显示未知发布者。校验文件与更新清单随安装包提供。
