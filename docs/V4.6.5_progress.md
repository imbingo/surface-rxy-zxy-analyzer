# V4.6.5 implementation checkpoints

## Batch 1: provenance and display-isolation baseline

Implemented a read-only `data_scale` module and persistent provenance strip.
Counts distinguish source records, source finite points, theoretical matrix
positions, mapped analysis input, final calculation points, and displayed points.
Unknown source counts remain unknown, not zero or the imported sample size.
Legacy stride can stop early and is deliberately not trusted as a source total.
Known full-scan matrix, Zygo, Precitec and spatial-grid counts are reused.
Column remapping invalidates sampled source validity; full import can count its
finite XYZ after mapping. No extra file scan, changed sampling algorithm, or
measurement definition is introduced in this batch.

Source totals that have not been counted remain unknown. The optional explicit
full-file counting action is not implemented yet. Source-count persistence and
report metadata will be integrated with batch 3.

Added seven tests, including actual GUI display refresh at limits 10000, 30000,
60000 with assertions that metrics and active indices do not change and analysis
is not called. The 1366x768 provenance-strip screenshot was inspected.

## Batch 2: XY rendering checkpoint

Implemented full-input physical XY binning (count, finite-Z count, mean Z,
ROI occupancy), height/density/missing modes and a 50,000-point automatic
threshold. Empty height cells are transparent; missing mode uses neutral gray.
Density is log1p(bin count), not a metrology metric. No interpolation, fabricated
analysis points or changes to source topology are introduced.

The GUI uses a dedicated one-worker display executor, 200 ms debounce, source
generation and request generation checks, and a two-entry viewport cache.
Only the GUI thread touches artists. Each full plot refresh resets source/cache;
zoom/pan only rebuilds display bins. Resolution follows the actual axes pixel
size, capped at 1200 per side. Source snapshots are separate indexed arrays.
Smart seed selection now queries physical XY over all undeleted source
candidates, excluding nonfinite XYZ, not the display sample.

Tests cover edges, means, ROI occupancy, physically absent circular data,
irregular XY, bounded resolution, viewport rebuilding, mode-switch metric
identity, source-index seed selection and rejection of a completed stale job.
Screenshots were captured at 1366x768, 1600x900, 1920x1080 and 900x640.
At 900x640 existing KPI cards have clipped text; this remains a final UI release
blocker, not a passed visual acceptance. Existing symbolic transform icons also
need a packaged/font check. No installer is delivered at this checkpoint.

Local single-run NumPy raster benchmark, 1000x800, includes tracemalloc overhead:

| Input | Build seconds | Traced peak allocation MiB |
|---|---:|---:|
| 100k | 0.0272 | 36.1 |
| 500k | 0.0482 | 58.2 |
| 1M | 0.0768 | 85.8 |
| 2M | 0.1754 | 144.2 |

These are raster-kernel timings, not end-to-end paint latency or total process
memory. Full benchmarks, LOD, report and release QA remain batch 3 work.
