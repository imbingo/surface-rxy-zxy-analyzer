# V4.6.3 架构审查

基线：4ec8fb4。此文为静态结构审查和有限运行检查，不是全场景性能基准。只新增审查文档，未重构实现。

## 判断

作为单机测量工具，Python + Qt + NumPy/SciPy + Matplotlib 的技术选择合理。工程已由旧单文件拆成多个文件，数值算法、公共API、任务执行和部分绘图帮助函数已可复用。但七个Mixin仍合成为同一个主窗口对象，业务状态、界面和计算边界不够清晰，处于“拆文件后、业务模块独立前”的阶段。

不建议仅以减少行数为目标重写。主要收益应来自统一结果状态、缩小模块职责和减少重复计算/重绘。

## 结构和实现负担

### 1. 主窗口承担共享业务状态

SurfaceAnalyzerPro继承7个业务Mixin。静态统计app.py引用338种self属性名，其中包含控件、方法及数据；该数字不等同338个业务变量，但显示接口面很宽。data_io、ROI、gap、reporting等均通过同一个self访问当前数据、指标和界面。

前轮F01/F02就是状态归属不明确的具体表现：胶厚快照、主控筛选后的结果和失效标志可以不同步。

建议先定义显式的Dataset/AnalysisResult/GapResult结构，携带源数据版本、参数快照、坐标变换、有效点、单位、质量/有效性信息。图、表、导出消费同一结果，UI不充当计算接口。

### 2. 导入模块混合设备解析、策略和设置窗口

data_io.py包含多种设备格式、矩阵/点云采样、单位映射、大文件设置对话框、导入状态等。show_bigfile_settings_dialog为364行，_read_precitec_fss为280行，_read_table为250行。

建议把纯解析器、导入配置和Qt界面分开，先保留现有分派接口作为兼容适配层。API file_io.py明确只支持常规XYZ，与GUI设备解析器功能不完全相同；当前存在两条解析路径，未来应复用适用的底层解析与单位规范，不能贸然把不同职责合并。

### 3. 交互路径重复计算和全图重建

update_analysis在界面线程执行分析与绘图，每次都调用平面指标及1/2/3阶曲面拟合，即使当前只看原始面型。这里平面与一阶多项式的模型有重复求解，但法向/竖向残差口径不同，合并时必须保留该区别。

GapMatchCanvas.plot_registration每次清空Figure并重建Axes、点图、图例、布局。拖动信号约35ms节流只限制请求频率，不保证每次重绘能在35ms完成。主控draw_plots也清空四视图重建。

建议按数据/参数版本缓存拟合；按需生成高阶结果，完整报告导出时补齐所需阶数；拖动仅更新散点坐标与高亮集合，保持Axes、布局及图例稳定。先测分析/绘图耗时再做后台化，不承诺未经基准的性能倍数。

### 4. 无界面API依赖没有真正隔离

api.py导入mixins.analysis会先执行mixins/__init__.py，后者立即导入所有Mixin。因此一次仅导入analyze_xyz的进程也加载PyQt6.QtWidgets、matplotlib.pyplot、widgets、data_io和reporting。本机单次检查约1.10秒，仅用于证明依赖链，不作为可靠启动性能基准。

建议把纯分析算法放入独立模块，并避免Mixin包初始化时导入全部界面模块，使数值计算可以脱离Qt依赖测试和使用。

### 5. 有清理空间，但不是大量完全复制的函数

AST检查函数体超过12行的完全一致副本，本轮未找到。不能据此排除语义相近的重复逻辑。

旧模块拆分遗留大量静态未引用导入候选：data_io 34个、roi 45个、reporting 42个。需考虑再导出或导入副作用后再清理；重复import本身有Python缓存，不意味着每次都重新加载整个库。此项主要改善依赖清晰度，不应宣传为主要运行加速。

## 渐进改造顺序

1. 修复并补测试覆盖F01—F04，先把结果一致性锁住。
2. 引入显式结果快照与数据版本，统一失效和导出规则；保留原界面入口。
3. 提取独立数值服务、格式解析器；保留旧API和Recipe兼容，明确验证单位和缺失值。
4. 根据计时数据优化高阶拟合缓存、拖动重绘，逐步把耗时计算放入已有任务框架。
5. 拆页面/设置对话框，清理静态未引用依赖和经确认可退休的兼容入口。

目标结构可保持简单：ui / services / io / models / reports，加现有tests。仍是一个桌面程序，不需要网络微服务、复杂插件框架或为了分层制造大量小类。

完成标准是同一输入指标一致、结果可追溯、交互流畅、模块可独立验证；不是总代码必须降到某个行数。改造初期因快照、适配层和回归测试增加，代码量可以暂时上升。
