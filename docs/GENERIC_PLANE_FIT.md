# 通用三维拟合

扩展 ID 为 `generic-plane-fit`，扩展版本为 1.2.0，最低主程序版本为 V5.0.9。此目录是源码扩展包，可将 `extensions/generic-plane-fit/` 复制到
`%LOCALAPPDATA%/SurfaceRxyZxyAnalyzer/module_extensions/` 后重启主程序。
Linux 默认位置为 `~/.local/share/SurfaceRxyZxyAnalyzer/module_extensions/`。
用同一份源码运行主程序。已发布的 V5.0.8 缺少 `xyz_selection_v1` 能力，
扩展管理会显示加载失败和具体原因。

## 从主控写入测点

1. 在「单层」导入含测面或定位点的物理 XYZ 点表。确认各轴列映射和输入单位，保留共同的机器坐标系或共同工件坐标系。
2. 使用「原始 Z」，关闭高度滤波并撤销主控姿态变换。在「ROI」选择「矩形 ROI」并开始框选。XY 重叠时，在能分开测面的 XZ 或 YZ 视图拖框。启用的同投影矩形取并集，不同投影取交集。可以结合原有手动删点保留需要的测点。
3. 打开左侧「通用三维拟合」，在「基准面 A」点击「写入当前数据」。
4. 回到「单层」，删除、停用或清空前一个 ROI，以恢复投影视图中的候选点。用第二个矩形 ROI 选出测量面，再打开扩展并写入「测量面 B」。
5. 点击「拟合并比较」。写入一个槽后也可查看单面结果。重写任一槽会清空旧结果。之后在主控更换文件或处理参数时，已写入的槽位和已完成的结果仍与原快照对应。

主控的高度面指标不可用时，相应指标卡会显示「不可用」，悬停可查看原因。正交投影视图和矩形 ROI 仍可使用。
三维图中的蓝色为 A，橙色为 B，箭头表示各自按约定取符号的单位法向量。
拖动结果图可旋转共同坐标视图。较窄或较矮的窗口可向下滚动查看质量指标和定义。

## 选择比较坐标系

- **原坐标系**是默认选项。按导入的共同坐标轴计算 B−A 的投影倾角差。
- **基准面 A 坐标系**以 A 的拟合质心为原点，A 的约定法向为 Z′。从原 +X、+Y 或 +Z 轴选择一条，将其向 A 面投影并归一化得到 X′，再以 Z′ × X′ 得到 Y′。自动选项用投影最长的原轴，数值近似并列时按 X、Y、Z 排序。若手选轴投影长度小于 0.001，请另选参考轴。
  两面的法向通过同一组轴表达。A 的两个倾角均为 0°，B 的两个倾角就是此坐标系下的 Δ。若 B 与 A 垂直，某个投影仍可能退化。选择参考轴会改变两个分量所对应的物理方向。
- **三点建基准 · 测 B**。用主控 ROI 或删点保留恰好三个定位点，写入 A。按面板上的点号及 XYZ，指定左底点、右底点、顶点。选择后立即预览三轴。拟合 B 后，顶部 Rx／Ry 表示 B 相对于三点基准的 X′Y′ 平面倾角。
- **两面定基准 · 测 C**。把 X′ 参考面写入 A，Y′ 参考面写入 B，待测面写入 C。默认两面等权，以法向夹角的两条平分线求正交轴，也可指定 A 或 B 为主方向。两面法向符号沿用拟合的确定性约定，适用于类似 YZ／XZ 平晶的布置。两面近似平行时拒绝定轴。拟合后可读 A／B 夹角及偏离直角、C 相对基准的 Rx／Ry 和总倾角。两面定轴只需方向。
- C 恰好有三个点时，也可为 C 指定底点和顶点，比较三点坐标系与外部基准的完整旋转。界面显示旋转角大小（0°–180°），JSON 保存目标三轴在参考坐标系中的旋转矩阵，列依次为目标 +X、+Y、+Z。
- 切换后立即更新比较值。三维图、各面拟合参数与主控均以原坐标显示。JSON v3 的 `comparison` 记录基准规则、原始夹角、坐标基与诊断，`slots` 保存原坐标系拟合与点集。顶层 `delta_rx_deg`、`delta_ry_deg` 对应顶部当前读数，在两种建基准模式下为待测面相对 X′Y′ 的投影倾角。

### 三点坐标轴

用左底点指向右底点定 +X′，用顶点到三维底边直线的垂足指向顶点定 +Y′，用 X′ × Y′ 定 +Z′。底边中点为原点，近似等腰时仍使用同样的轴方向。图中红、绿、蓝分别表示 X′、Y′、Z′。三点共线或近似共线时，界面提示无法稳定建系。输入为已取得的实际定位点或承载点，球心拟合和接触点推算属于后续工作。

## 拟合、角度与质量

拟合平面为 `nₓX + nᵧY + n_zZ + D = 0`，法向量 `n` 的长度为 1。
对中心化后的 XYZ 点做 SVD，取最小奇异值对应的右奇异向量作为法向量，
以 `D = −n·centroid` 求平面常数。此法最小化全部测点到平面的正交距离平方和。
完全重复的 XYZ 测量按原测量次数计权，同时标出重复数量。
按坐标排序后拟合，点输入顺序变化不影响法向量符号。
将绝对值最大的法向分量定为正。分量绝对值在最大值的 `10⁻⁸` 范围内时，
按 Z、X、Y 的顺序选择。这是一项可复现的无向平面表示约定。
当主导分量越过约定交界时，法向量可能整体换号，投影角保持 180° 周期等价。
测点本身无法确定材料的内外方向。

- `Rx = wrap₁₈₀(atan2(−nᵧ, n_z))`，`Ry = wrap₁₈₀(atan2(nₓ, n_z))`。换算为度后归入 `[−90°, 90°)`。对可表示为 `Z = aX + bY + c` 的普通测面，与旧定义 `atan(b)`、`atan(−a)` 的方向一致。Rx、Ry 是投影倾角，法向量是平面方向的空间表示。
- `ΔRx = wrap₁₈₀(Rx_B − Rx_A)`，`ΔRy = wrap₁₈₀(Ry_B − Ry_A)`。两项均为 B 相对 A 的最短有符号差，区间同上。正好相差 90° 时统一取 −90°。
- 计算某角度所用的两个法向分量，其投影长度若小于或等于 `10⁻¹²`，相应角度和 Δ 显示「不可定义」。投影长度介于 `10⁻¹²` 和 `10⁻³` 时标记为敏感，界面使用近似符号和一位小数。此标记描述数值敏感性。
- 有符号法向距离为 `d = n·p + D`。质量指标为 `√mean(d²)` 和 `max|d|`，界面以 µm 显示。JSON 中的 XYZ、D、距离和拟合质量以 mm 保存，角度以度保存。
- 拟合需至少三个不同的有限坐标点。令奇异值为 `s₁ ≥ s₂ ≥ s₃`。若 `s₂ ≤ 10⁻⁶s₁` 或 `s₃ ≥ 0.98s₂`，拒绝给出法向量。若 `s₂ < 10⁻³s₁` 或 `s₃ ≥ 0.2s₂`，标记测点分布窄或法向散布大。阈值用于诊断选区。

## 快照与兼容性

「查看写入参数」显示每槽自己的来源、列映射、输入单位、ROI、滤波和删点记录。
顶部「导出拟合结果」可导出同一次结果的 JSON，包括已写入的 XYZ 点集、处理参数、
有效点索引、拟合参数和逐点有符号距离，以及失败原因和质量标记。
`point_indices` 是主控映射后点集从零开始的位置，
`reader_index_labels` 是导入表的索引标签，可追溯到列映射前的表记录。
点表读取器会跳过头部、空行或坏记录，因此这些字段没有原文件物理行号的含义。

主程序增加了可选的 `ModuleHost.current_xyz_selection_snapshot()` 接口和能力声明。
主控保留点表经映射得到的三维坐标，在高度面拟合失败时仍绘制点集并保留选区工具。
大量点的侧视图各自抽取显示点，ROI 继续在完整映射点集上计算。已有面型和滤波公式沿用原定义。

## 使用边界

- 参与同一次比较的快照须来自同一次列映射。跨文件配准以及坐标系一致性声明需另行设计。
- 写入采用未抽样的物理 XYZ 点表及原始坐标列。主控现有文件导入上限仍适用；超限文件若进入抽样模式，请先准备保留完整测面的点表。
- 扩展允许矩形 ROI 和手动删点。写入时要求原始 Z、滤波关闭、无姿态变换，避免把高度滤波、残差或逐面变换的结果用作相对姿态。完整空间交互选区和三维滤波留给后续工作。
- JSON 保存交互会话结果。后续接入 Recipe／批量时，可为两槽保存独立的源文件角色、已应用列映射和 ROI，并遵守现有删点重放的源文件校验与位置约束。

## 主控 3D 默认视角

导入或重置后以 45° 仰角、−135° 方位角进入对角视图。主控根据画布宽高和轴标签适配投影大小，竖直点云也使用同一适配过程。双击 3D 图可回到默认视角和尺寸。
