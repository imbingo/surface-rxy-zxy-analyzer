# V4.6.8

- XY 图题同一行提供“面型图 / 原始点图”切换，不新增工具行，移除点密度显示。
- 面型图改为按估计扫描步距自适应的栅格，不再随画布像素无限细分；空栅格仍透明，不插值补洞。
- 原始点图显示真实 XY 坐标，超过 50,000 点时采用空间显示抽样并保留高度极值，放大到局部后恢复窗内全部有效点。
- 点击 XY 放大按钮后面型图使用更细的细节栅格，小孔在放大状态下更易辨认。
- 修复框选、取消框选时 XY 底图短暂消失再出现的问题；选中高亮不再清除底图与显示缓存。
- 切换模式保持缩放、色标和选区，不重新计算指标；Recipe 与报告同步支持两种模式。

Recipe schema 保持 8；量测计算口径与原有 PV、Rx/Ry 定义保持不变。完整回归 201 项通过。

适用 Windows 10/11 x64。Setup 内含 Python 和依赖，默认安装到 Program Files，支持已有版本覆盖升级。用户设置保留在安装目录之外；升级前请保存当前未导出的工作。安装包未签名，Windows SmartScreen 可能显示未知发布者。校验文件与更新清单随安装包提供。
