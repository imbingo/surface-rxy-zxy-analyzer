# V4.6.8 — XY 面型图 / 原始点图

## 本轮边界

基于 V4.6.7（a4cb118），只调整 XY 显示及关联 Recipe / 报告，保留姿态变换图标、底部信息条、导入进度、Recipe 库和智能 ROI 内联预览。量测定义、源点云和 Recipe schema 8 不变。本轮为本地源码交付，不代表已经打包安装程序或发布 GitHub Release。

## 操作

后续优化（同版本）：普通框选、取消框选和进入 ROI 框选模式只更新选中高亮，不清底图、不重建显示缓存。测试在 XY/XZ/YZ 选择及取消操作中检查每次绘图事件的底图可见性、对象身份、缓存代次、指标和坐标范围。点击 XY 单图放大按钮后，面型图按估计步距的 1.08 倍生成细节栅格，降低概览的 1.25 倍余量；底部标注“细节”。保留 8% 余量是为了避免非线性运动误差在恰好一倍步距栅格中造成假的白色条纹，截图检查已排除此问题。仍受像素预算约束，不能保证分辨小于采样间距或屏幕像素的孔，步距估计不理想时可能保留更多碎空格。模拟 0.1 mm 步距、带运动误差的数据验证了 0.32 mm 无数据孔中心透明，同时内部栅格占用率超过 99.9%。

- XY 图题右侧提供“面型图 / 原始点图”下拉框，与单图放大按钮同一行，不占额外绘图区工具行。
- 默认面型图：全部显示源参与高度均值栅格聚合，空栅格透明，不插值、不生成数据点。
- 原始点图：真实 XY/Z 坐标、固定屏幕点大小；窗内超过 50,000 个有效点时采用空间显示抽样，并保留当前高度通道极值。底部和图题悬停提示实际绘制点数及抽样状态。放大至预算内恢复窗内全部有效点。
- 切换只请求 XY 重绘，保留坐标范围、色标、临时选点与 ROI，不重新运行分析，也不刷新其余三图。
- 点密度和高度＋缺测不再作为可用模式；旧 Recipe 中 `density` / `missing` 安全迁移为 `height`，新 `points` 可保存和恢复。
- 报告跟随模式，原始点图超限时图题明确标注“显示抽样”。CSV 与量测指标未改变。

## 面型图显示规则与限制

新增独立的 `rendering/xy_display.py`。首次显示在工作线程中对完整有限 XY 建立近邻树，最多查询 4096 个位置、每位置最多 32 个近邻，分别估计 X/Y 主方向步距；无法取得方向邻居时回退至局部最近邻尺度。树只在估计期间存在，缓存步距和源坐标锚点，不缓存整个树。

基础格宽为估计步距的 1.25 倍，为小幅轴组运动误差留出余量；根据画布像素预算按整数倍降分辨率。栅格锚定源坐标而非当前视窗边缘，放大时不无限细化，小幅平移不随意改变格子相位。为了显示窗边处完整单元，会聚合落在边缘单元内的源点；底部“窗内点数”仍按实际坐标窗口统计。

这只是显示尺度估计，不是扫描仪标定，也不是孔洞判定。点云极端不均匀、强旋转、极端各向异性或密集重复坐标可能使步距估计不理想。栅格的物理面积代表聚合单元，并不证明其整个面积均被探头测过；小于栅格的孔缝和孤立丢点可能不能分辨。需要检查真实点位时切换原始点图并放大到未抽样状态；该模式也只能看到当前分析数据，不能恢复导入时已预抽样丢弃的记录。

## 验证

- 30×30 mm、0.1 mm 步距，叠加 ±0.015 mm 平滑非线性及 0.001 mm 标准差随机运动误差：多种像素尺寸和缩放下，内部区域栅格占用率大于 96%。
- 圆形无数据区和 1 mm 条带间隔的内部仍透明；不通过全局占用率“补满”孔区。
- 非等距 X/Y 步距、乱序、重复点、原始点预算、真实坐标、极值保留与局部全点验证。
- GUI 验证模式切换、缩放、固定色标、临时选点、ROI、过期请求丢弃、Recipe 迁移/回存、报告两种模式。
- `scripts/preview_v468.py` 输出四种尺寸（1366×768、1600×900、1920×1080、900×640）及单图聚焦截图，均使用明确标注的模拟扫描数据。
- 源码入口 `start_surface_analyzer_v4_6_8.bat --check` 已验证 V4.6.8 模块正常导入。

200 万点合成规则网格的本机单次显示核心计时：首次面型图 0.844 秒、缓存步距的缩放 0.049 秒、原始点模式空间抽样 1.412 秒（绘制候选 49,954 点）。不包含文件导入、Matplotlib/Qt 绘制或端到端延迟，不是最坏性能保证；首次步距估计另有全量 XY 树的内存开销。

初版完整回归：199 项测试全部通过（77.201 秒）。框选稳定性及细节显示优化后的最终回归：201 项测试全部通过（89.505 秒），日志 `audit_outputs/v468_push_verified.log`；V4.6.8 启动检查再次通过。截图及日志为本地产物，不进入源码发布内容。
