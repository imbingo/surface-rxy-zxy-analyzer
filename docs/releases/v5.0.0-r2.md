# V5.0.0 更新版 2

产品版本继续保持 V5.0.0，本次使用独立发布标签 v5.0.0-r2，不替换此前 v5.0.0 的安装包。

- 新增数据预览与 Excel 式派生列：右键插列、命名、点选公式、相对 / 绝对引用、填充柄、Ctrl+D、撤销 / 重做；可从 Up / Down 生成分析 Z。
- 新单元格公式使用 Recipe schema 11，支持旧 schema 9 / 10；批量处理与导出保留公式追溯。旧版软件不能读取 schema 11，请保留旧 Recipe 的副本。
- 导入策略移到数据文件上方；解析器信息移入导入详情；XYZ 不再显示矩阵默认 Pitch。矩阵 Auto 缺少可靠 X/Y Pitch 时要求明确补充，不静默使用历史默认值；保留明确手动设置。
- 左侧参数区按窗口设置默认宽度，并记忆手动调整。
- 新增自动 / 全局统一色标。自动模式下 XY 使用全部未删除点，3D/XZ/YZ 共用最终有效 ROI 的局部范围；报告同步显示全局和局部色条。删点 / 恢复后更新范围，缩放与显示降采样不改变范围。
- 单层图标采用曲面网格。Rx、Ry、PV、TTV、RMS、Mean Z 的量测定义不变。

## 安装说明

适用于 Windows x64，Setup 内置 Python 与运行依赖。安装前退出软件；已安装 V5.0.0 的用户请手动运行此更新版 Setup 覆盖安装。产品版本号相同，不能依赖仅按版本号比较的自动更新提示。

默认安装到 Program Files，需要管理员权限；支持选择仅为当前用户安装。保持原安装身份和卸载入口。Recipe 与用户配置位于安装目录之外，升级和卸载不主动删除这些数据。

安装包未进行代码签名，Windows SmartScreen 可能显示未知发布者。下载后可使用随附 SHA-256 文件核对完整性。
