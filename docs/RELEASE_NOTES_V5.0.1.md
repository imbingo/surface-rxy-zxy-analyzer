# V5.0.1 — 自动滤波色标修复

- MAD、局部中位数和迭代 σ 裁剪剔除的异常点不再参与全局色标范围计算。
- 保留 ROI 外未参与本次滤波的正常总览上下文；不对 ROI 外数据额外滤波，也不改变原有量测或滤波定义。
- 自动/全局统一模式、单层界面、单次报告及批量报告采用相同规则；色标仍以显示抽样之前的数据计算。
- 关闭滤波、撤销手动删点或切换 ROI 时，按当前有效分析范围重新统计；滤波未生效/退回未滤波时不隐藏数据范围。
- 版本号及 Windows 安装器默认版本更新为 V5.0.1，增加对应源码启动入口。未构建或发布 Windows 安装包。

自动滤波剔除点可继续作为总览背景显示，但以修正后的色标着色，可能饱和在色标端点；本次仅修改色标统计，不删除源数据。
