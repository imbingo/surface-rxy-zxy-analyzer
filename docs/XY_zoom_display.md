# XY 缩放显示修正（V4.6.5，不改变量测定义）

- 总览继续使用全显示源 Raster；空网格透明，不插值。
- 窗内不超过 50,000 个点，且每个非空网格平均不超过 1.4 个点时，切换为原始散点。散点模式退出阈值为 1.8，减少阈值附近反复切换。
- 散点使用真实源坐标、固定 9 pt² 标记、不透明高度颜色；点标记的大小不是实际物理尺寸，不能靠标记边缘量孔径。
- Raster 和散点共用当前显示源有限 XYZ 的 Z 最小/最大值。平移、缩放不重设色标；改变数据或高度/残差通道会重新建立色标。
- 散点索引在后台准备，最多 50,000 个；仅作显示，不改 ROI、拟合或指标数据。灰色 ROI 标记仍独立覆盖。
- 缩小恢复 Raster；纯空白视口清空散点；过期后台结果不能覆盖新视口。

验证：固定色标、模式往返、固定点大小、空孔视口、源索引、过期任务与量测不变测试。
`scripts/preview_hole_demo.py` 可对已生成的带孔 Demo 截取总览和孔区放大图。
