# V4.7.1 — 导入稳定性修复 + 迭代σ裁剪残差模型扩展

V4.7.1 在正式读取前使用有界样本检查所选导入策略。明显不匹配的 Physical XYZ、Pixel XY、Z Matrix 和 Zygo 文件会快速失败并给出建议；逐行解析还会在连续失败或早期有效率过低时终止。取消检查覆盖格式探测、metadata、正文定位、矩阵扫描、采样及源数据统计。失败或取消的新导入不会替换此前有效的数据、ROI、视图、平行度寄存器和指标。

迭代 σ 裁剪新增一阶平面、完整二阶曲面、完整三阶曲面和跟随当前去残差阶数。高阶模型沿用现有 X/Y 归一化多项式核心，并检查空间覆盖、近似共线、矩阵秩和条件数。自动降阶会在界面和导出元数据中记录实际阶数与原因。

残差模型只决定异常点的删除。最终保留点集仍统一进入既有一阶最佳拟合平面量测，Rx、Ry、PV、TTV、RMS 和 Mean Z 定义没有变化。旧 Recipe 缺少 `sigma_residual_order` 时默认 `order1`。
