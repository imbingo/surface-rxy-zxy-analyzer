# V5.0.5 — 单层导出有效点原点归零

- 单层导出新增可选「导出坐标按有效点左下角归零」：默认关闭，勾选状态会记住。
- 开启后，根据删点、ROI、滤波后最终参与计算的点，将导出 CSV 和报告图中的最小 X、Y 平移到 0；界面坐标、ROI 与删除框、Recipe 不变。
- CSV 的 Z、残差列及拟合平面系数仍按界面坐标计算；Rx、Ry、PV 不变。CSV 元数据和报告图均注明导出坐标原点与偏移。
- 膜厚和平行度模块导出不受影响。

## 使用与限制

完成单层分析后，在「导出报告」菜单中勾选「导出坐标按有效点左下角归零」。默认关闭；设置自动记忆。偏移只用于单层 CSV 和报告图，不写回数据、界面坐标、变换路径或 Recipe。

## 发布验证

定向回归与工作区检查由本次 V5.0.5 发布流程执行；构建和安装验收结果以对应 GitHub Actions 记录为准。

## 安装

Windows x64 完整 Setup 由 GitHub Actions 构建，发布后附 SHA-256 与 update_manifest.json。安装包沿用原 AppId 支持升级，可选择当前用户安装。安装包未进行代码签名，Windows 可能提示未知发布者。
