# V5.0.4 — VR 导入修复、组合 Recipe 与批量运行

- 修复 Keyence VR 高度矩阵因大量前导空白、分隔符空记录及长元数据而无法导入的问题。预检区分未覆盖正文与格式错误，手动起始行参与定位，保留可靠 Pitch、单位、矩阵行列及缺测位置；搜索有资源上限、进度和取消。
- 膜厚和平行度新增“保存组合 Recipe”：每个槽内嵌写入时的独立完整单层参数。旧槽缺快照时需重新写入，不使用当前界面补齐。
- 支持按角色指定单组文件，以及每个直接子文件夹一组的批量确认表。严格区分缺失、歧义、冲突，不按顺序猜角色；配方要求单片 2 时不自动降级。
- 每组隔离执行现有单层导入、单位、变换、滤波、ROI 与分析，再调用现有配准及膜厚／平行度计算。支持失败继续、取消、超时和统一质量策略。
- 独立输出报告、CSV、批量汇总与追溯记录，包含实际输入哈希、各槽参数、质量标记和配准设置；失败组不沿用上一组指标。
- 膜厚手工／自动写槽统一采用单层实际处理后的 Z（包含高斯结果）。Rx、Ry、PV、TTV、RMS、Mean Z、拟合、配准和扣减公式不变。

## 使用与限制

分别在单层处理文件并写槽 → 在膜厚／平行度“计算与导出”保存组合 Recipe → Recipe 管理加载 → 按角色选文件或扫描根目录 → 确认运行。

第一版按组串行、不递归目录，不包含嵌套组合 Recipe。内存或 Gap 计算结果需先导出为独立数据文件，再导入写槽。自动配准未接受的组明确失败。手动删除仍受源哈希及抽样签名校验；开始前选择失败或跳过并标记策略。

## 发布验证

本地发布前定向回归 **132 项测试、37 个子用例通过**，源端工作区和组合进程验收通过。

发布流水线仅运行有超时保护的相关回归，不运行存在既有 Pitch fixture 失败与模态停滞风险的全量套件。新增源程序／打包程序组合验收，覆盖真实子进程连续分组、失败继续、三层扣减、报告及取消；校验源提交和版本。安装验证覆盖清洁安装、V5.0.3 升级、卸载及用户设置／Recipe 保留。具体结果以本次成功的 Actions 构建记录为准。

## 安装

Windows x64 完整 Setup，沿用原 AppId 支持升级，可选择当前用户安装；附 SHA-256 与 update_manifest.json。可选格式扩展不包含在主安装包中。安装包未进行代码签名，Windows 可能提示未知发布者。
