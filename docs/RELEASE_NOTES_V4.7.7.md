# V4.7.7 — 可选格式扩展

主程序新增 API v1 格式扩展入口。Sensofar PLUX 为独立可选安装包，不包含在主程序中。

1. 安装 / 升级主程序至 V4.7.7。
2. 安装 SurfaceAnalyzer_SensofarPLUX_Setup_V1.0.0.exe。
3. 重启主程序，从“载入数据”选择 .plux。

“保存 Recipe”菜单 → “格式扩展管理”可查看版本、支持格式和状态，启用 / 禁用或打开扩展目录。
数据加载、批量导入、取消、失败回滚及分析上限共用主程序流程。
报告及 CSV 记录扩展 ID、版本和高度层。

PLUX 1.0.0 支持已知单高度层结构，按元数据读取像素间距及 float32 高度；
NaN 仍为孔洞，保留矩阵行列索引。坐标采用局部像素坐标，台面位置仅保留元数据。
多高度层及未知结构明确拒绝。尚未取得用户真实文件与原厂导出对照，需完成该验证后才适合正式量测验收。

扩展安装在当前用户的 LocalAppData，可独立卸载；主程序升级保留扩展。
后续厂商按 [扩展 API](FORMAT_EXTENSION_API.md) 增加独立 reader，无需修改现有量测算法。
