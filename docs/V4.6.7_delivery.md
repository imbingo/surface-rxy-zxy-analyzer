# V4.6.7 本地交付说明

智能抓面补充：直接复用主控 XY 俯视图，已纳入区域逐渐覆盖灰色，图内浮层显示当前阶段、百分比、点数、用时与取消按钮。最多预览 12,000 个点，约 300 ms 更新一次；缓存底图并只更新灰色覆盖层，不生成第二张点云视图。手动删除点不进入过程显示。连续曲面与严格同平面模式均支持；完成后转为正式 ROI 并保留 XY 坐标范围，取消或失败移除临时层并保留之前的 ROI。

- 实时 Rx / Ry 卡片采用 PV 同款蓝色高亮。
- 数据导入弹窗按识别、读取、映射、首次分析展示环形百分比、阶段状态和用时。读取阶段可取消；应用数据时取消关闭，完成后自动收起，失败或取消可查看原因并关闭。导入后的数据规模链仍在底部显示。
- 环形进度依据实际导入阶段推进，不是时间预测；底层整块读取与同步映射/分析仍需等待单次调用结束，后续可进一步拆分计算。
- 参照 SOMA 的常用操作增加 Recipe 管理：搜索、收藏、最近使用、批量导入、双击加载、保存当前参数、导出所选和打开配方库。
- 本机库默认位于用户 LOCALAPPDATA/SurfaceRxyZxyAnalyzer/recipes，安装升级不覆盖。保存同名参数会新建文件；重复导入相同参数复用已有文件。文件与库索引采用原子写入。
- Recipe schema 保持 8；本轮提供本地版本供体验，未发布。
