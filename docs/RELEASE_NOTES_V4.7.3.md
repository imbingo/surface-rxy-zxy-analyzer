# V4.7.3 发布说明

V4.7.3 新增孔洞感知的空间高斯低通，用于抑制面阵干涉等数据中的高空间频率 Z 噪声，使 3D、X-Z 和 Y-Z 视图中的有效曲面趋势更容易观察。

## 空间高斯低通

在“异常点滤波”中选择“空间高斯低通（孔洞保持）”，并用毫米设置空间标准差 σ。滤波作用半径约为 3σ。σ 越大，曲面越平滑，同时横向空间分辨率越低。

规则 Z Matrix 和具有矩阵拓扑的 Pixel XY 数据使用有效掩码归一化二维高斯。普通 Physical XYZ 和其他不规则点云使用半径受限的空间邻域高斯。算法保持原始 XY、有效点数和孔洞，不会在缺失区域内生成新点。

滤波在当前未删除且位于有效 ROI 的点集上运行。手动删除点、无效点和 ROI 外点不参与邻域权重。超过 250,000 个分析点时，滤波在可取消后台任务中执行。

## 显示与量测

启用后，3D、X-Z、Y-Z 和面型图使用滤波后 Z，量测指标也基于该滤波后 Z 按既有公式重新计算。Rx、Ry、PV、TTV、RMS 和 Mean Z 的数学定义没有改变，但输入高度已经经过低通，因此 PV、TTV 和 RMS 可能降低。

CSV 同时保存 `Z_um`、`Z_raw_um` 和 `Gaussian_removed_um`，便于核对滤波后的高度、原始高度及被移除的高频分量。报告记录 σ、作用半径、算法路径、点数及 Z 变化 RMS。

## 兼容性

空间高斯默认关闭。MAD、局部中位数和迭代 σ 裁剪的行为保持不变。Recipe 升级到 schema 9；旧 Recipe 没有高斯参数时保持原滤波模式，不会自动启用低通。
