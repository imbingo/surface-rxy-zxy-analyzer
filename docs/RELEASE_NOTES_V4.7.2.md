# V4.7.2 发布说明

V4.7.2 统一了所有导入路径的分析输入硬上限，并修复 Smart ROI 在拓扑构建阶段仍可能使用已删除点或手动 ROI 外点的问题。

## 导入分析硬上限

开启自动抽样后，Physical XYZ、Pixel XY、Z Matrix、Zygo、Precitec、Excel 和通用文本数据在进入分析状态前都会经过统一提交守卫，最终分析输入点数不超过“导入上限(行)”。文件大小低于 MB 触发阈值、但记录数或有效点数超过上限时同样会抽样。关闭自动抽样时允许全量分析，并在规模摘要中明确标识。

Z Matrix 的矩阵分析阈值仍用于决定何时提前采用矩阵抽样，但不再替代导入上限。最终分析输入同时受导入上限约束。各导入器会分别记录源记录数、源有效点、分析输入和抽样原因；无法准确统计源有效点时显示“未知”。

## Smart ROI 拓扑域

Smart ROI 现在先形成有效域，再选择候选点和构建连通拓扑。有效域由有限数值点、未被手动删除的点和当前手动 ROI 范围共同组成。已删除点与 ROI 外点不会进入 KDTree、Delaunay、adaptive kNN、matrix8、BFS 或连通分量，也不能充当跨空白区域的桥接节点。

Smart seed 仍只来自 XY 视图，并在有效域中匹配最近源点。点击删除区、ROI 外或距离有效点过远的位置会被拒绝。删除、恢复、ROI、导入、映射、变换和滤波变化会使相关缓存失效。

## 兼容性

Rx、Ry、PV、TTV、RMS 和 Mean Z 的计算定义未改变。Circle ROI 仍保持移除状态。既有 Recipe 与报告字段继续兼容。
