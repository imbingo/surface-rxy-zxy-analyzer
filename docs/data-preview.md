# 数据预览与 Excel 式派生列（V5.0.0）

数据页顺序：导入策略 → 数据文件 → 列映射与单位 → 批量与重置。在数据文件卡片点击“数据预览与派生”。源文件始终只读，产品版本不变。

## 新增与计算

1. 右键任一数据列标题，选择左侧 / 右侧插入派生列。
2. 双击新列标题命名，例如 Z_sum；原始列名称和值不可修改。
3. 选择新列第一条数据，输入 `=`，点击 Up 单元格，输入 `+`，再点击 Down 单元格。若 Up、Down 位于 C、D 列，公式为 `=C2+D2`。
4. Enter 提交当前单元格，Esc 取消编辑。公式栏保留表达式，表格显示计算结果；引用使用对应颜色。
5. 拖动单元格右下角填充柄填充可见范围；双击填充柄填充至全部分析输入的末行。也可选中范围后 Ctrl+D。向下填充起始于选中源单元格，不会覆盖它上方的行。
6. 右键结果列，选择“设为分析 Z”，明确输出单位，再点击“应用分析”。新增列、填充和选择 Z 均只修改草稿；成功应用才替换当前分析。

支持数字、科学计数法、括号、四则运算、跨行引用、相对 / 绝对 / 混合引用，例如 `=C2+D2`、`=$C$2+D2`、`=C$2+$D2`。不支持跨文件 / 跨工作表引用、函数库、幂运算或 Python 代码。最多 24 个派生列。公式不自动统一各输入单位；Up/Down 加减由设备定义决定。

## 行列身份与错误

- 表头视为第 1 行，数据从第 2 行开始。A/B/C 只分配给数据列；原始记录标识与参与状态通过选中单元格下方的辅助状态栏及行标题提示展示，不占公式列字母。
- 分页和筛选保持全局数据行号，公式按完整分析输入顺序求值，不按源文件物理行号求值。当前页最多 200 行。
- 筛选后的拖动 / Ctrl+D 只填写所选可见行；双击填充柄明确填写起始行至所有分析输入的末行，包括其他分页和隐藏行。
- 插列 / 改名不改变引用身份。删除派生列会提示依赖影响；确认后依赖公式显示 #REF!。原始列不能删除。
- 空值和非数值不补 0；除零 #DIV/0!、越界 / 删除引用 #REF!、循环依赖 #CYCLE!、非数值 #VALUE!、溢出 #NUM!。空白显示为空；错误 / 空白结果作为无效分析点处理。
- 支持撤销 / 重做插列、命名、编辑、删除、填充与 Z 选择；关闭时提供应用、放弃、继续编辑。

## 性能与状态

整列使用稀疏公式模板及区间覆盖，不为百万行创建公式对象或控件。按模板分组、分块向量化求值；跨公式依赖按就绪状态迭代解析。长的逐行递推依赖可能明显慢于同一行的列运算，仍在后台执行并可取消。操作使用不可变草稿快照；取消 / 失败不会提交部分结果。

分析列使用浅蓝背景；派生列标注 ƒx。选中记录展示参与计算、手动删除、ROI / 滤波排除、未映射或等待计算状态；最终参与行的行标题使用浅绿背景。引用列无需手写名称，点选即可输入地址。

## 源文件与网格

文本源文件每次最多 200 物理行 / 256 KiB，按字节偏移前进 / 后退，不全量重读或扫描总行数；长行可能分段。提供原始文本与通用点表字段预览。无法准确追溯的源物理行显示状态未知，不能用预览行位置猜测抽样结果。

矩阵 / Pixel / Zygo 共用分析输入工作表计算派生值；另有基于专用解析行列信息的局部 20×20 只读网格位置视图。格点提示显示已映射 X/Y、输入高度和状态。空格可能为无效点或未选中的抽样点，不能当作确定的 NoData。Excel / 二进制扩展查看专用解析后的输入，本轮不额外全量重读。Zygo 元数据、坐标和 NoData 语义不变；不包含多个矩阵的配准运算。

## Pitch 与导入详情

Physical XYZ 使用原始 X/Y 列及单位，不显示或套用矩阵 Pitch；抽样方式独立记录。解析器、字段完整性、回退原因移到“导入详情”。

矩阵新配置默认 Auto，只使用可靠文件校准值，必须有 X 和 Y 两轴；缺失或非正 / 非有限时要求手动补充，不静默使用历史 47.242。Auto 时隐藏手动数值输入；选择手动后可填写实际 Pitch。保留明确保存的手动设置。旧 Recipe 含 Pitch 数值而没有来源字段时按历史手动配置解释；没有数值时默认 Auto。

## 应用、Recipe 与输出

应用成功进入原有映射、单位换算、滤波、ROI 和指标流程，保留处理参数并重置手动删点（存在删点时事先提示）。寄存器保留快照，旧平行度结果沿用原有失效规则。Rx/Ry/PV/TTV/RMS/Mean Z 的定义不变。

无派生列导出 schema 9；旧式整列公式 schema 10 可转换为工作表模板；新工作表公式使用 schema 11，保存列身份、顺序、单位、公式及填充区间。整列末行使用开放结束范围，可适应下次不同记录数。跨文件按源列名称匹配，缺列 / 重名明确失败；新增无关源列可保留。批量与单次分析共用引擎。报告和 CSV 记录公式追溯。
