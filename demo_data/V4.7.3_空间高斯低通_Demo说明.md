# V4.7.3 空间高斯低通 Demo

本组数据用于比较同一多孔曲面的原始噪声、空间高斯低通结果和光滑参考面。

## 文件

- `V4.7.3_多孔曲面_面阵噪声版_XYZ.csv`：模拟面阵干涉仪的高频随机噪声、行列噪声和像素周期噪声。
- `V4.7.3_多孔曲面_光滑参考版_XYZ.csv`：相同 XY 点位、相同 36 个圆孔和相同真实低频曲面，不包含上述测量噪声。

两个文件各有 46,736 个有效点。坐标范围为 40 mm × 40 mm，列单位为：

```text
X_mm,Y_mm,Z_um
```

## 推荐测试步骤

1. 导入“面阵噪声版”，选择 `Physical XYZ`。
2. 确认 X/Y 单位为 mm，Z 单位为 µm。
3. 先关闭滤波，记录 X-Z、Y-Z、PV、TTV 和 RMS。
4. 选择“空间高斯低通（孔洞保持）”。
5. 将“空间σ”设置为 `0.35 mm`。
6. 比较滤波后的 X-Z/Y-Z 点带、指标及孔洞是否仍然存在。
7. 再导入“光滑参考版”，与滤波结果比较。

## 预期结果

使用 V4.7.3 核心 API 验证时，结果约为：

| 数据 | RMS (µm) | PV (µm) | TTV (µm) |
|---|---:|---:|---:|
| 面阵噪声版，关闭滤波 | 4.924 | 39.909 | 62.400 |
| 面阵噪声版，高斯 σ=0.35 mm | 2.542 | 14.758 | 41.336 |
| 光滑参考版 | 2.495 | 12.932 | 39.326 |

这里的参考面本身包含真实二阶/三阶低频形貌，所以去除一阶平面后的 RMS 不为零。高斯滤波结果应接近参考面，但不会与参考面完全相同。

## 注意

- 该 Demo 不含极端飞点，重点验证连续高频噪声的低通效果。
- 高斯滤波不会在圆孔内部创建点。
- σ 越大，X-Z 点带通常越细，但真实小尺度形貌也会损失。
- CSV 导出会同时包含滤波后高度、原始高度和被移除的高频分量。
